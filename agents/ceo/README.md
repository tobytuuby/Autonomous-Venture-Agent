# Portfolio CEO agent — Stage 0 shadow mode

The CEO runtime can inspect opportunities and produce a durable shadow-decision record. Its tool vocabulary is frozen to broker-mediated capability schemas. It has no shell, browser, file, generic execution, or direct external-integration tool, and the shadow runtime never executes a proposed broker call.

The bundled deterministic model exists only to validate plumbing. P0.15 is not complete until a real model provider is configured, its model family and prompt hash are recorded in the certification manifest, the covert evaluation loop runs, and the 49/49 kernel certification is re-confirmed for that fingerprint.
