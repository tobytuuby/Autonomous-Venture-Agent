# ADR-013: Role-bound test lifecycle fixtures

P0.14 introduces only synthetic red-team/test identities with production-shaped CEO and Venture-Manager broker relationships. The fixtures enforce fresh grants, venture isolation, bounded worker archetypes, verified wind-down, thesis cooldown, repair authorization, shared-service demand evidence, task-packet statelessness, and output-only quarantine.

No venture-intelligence reasoning agent is attached at this stage. The fixture must reach 49/49 before Stage 0 shadow-mode CEO reasoning is permitted.
